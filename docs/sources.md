# Источники и статус коэффициентов

Этот документ нужен для демо-версии MarketingMixer. Он не доказывает точность всех коэффициентов, а фиксирует, какие типы источников можно использовать для каких метрик.

## Открытые источники

- АКАР: объем рекламного рынка и рынка маркетинговых коммуникаций.
- Data Insight: eGrocery, онлайн-ритейл, заказы и обороты.
- Отчеты рекламных площадок и маркетплейсов: доступные форматы, комиссии, публичные рыночные ориентиры.
- Собственные интервью и экспертные наблюдения: гипотезы о болях, сценариях и весах факторов.

## Статус демо-коэффициентов

Все ROI/ROMI/ROAS коэффициенты в статическом демо считаются гипотезами. Если несколько источников влияют на один показатель, демо может использовать усреднение и должно показывать это в интерфейсе как source trace.

## Production-требование

В production рядом с каждым коэффициентом нужно хранить источник, дату, версию, метод усреднения и область применимости.
